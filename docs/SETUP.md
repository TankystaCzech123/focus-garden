# Setup

Focus Garden is an Expo (React Native) app with a local native module. There is no backend.

## Prerequisites

| | Android | iOS |
| --- | --- | --- |
| Node.js | 24+ | 24+ |
| Tooling | JDK 17, Android SDK (platform 36, build-tools, NDK), `adb` | macOS, Xcode, CocoaPods |
| Device | phone with USB debugging, or emulator (**without Google Play** if you want Device Owner) | real iPhone (the Screen Time API does not work in the simulator) |

Set `JAVA_HOME` (JDK 17) and `ANDROID_HOME` before building on Android.

## Run

```bash
npm install
npm run android      # = expo run:android
npm run ios          # = expo run:ios --device
npm run typecheck
npm test
```

`ios/` and `android/` are generated by `expo prebuild` and git-ignored. Re-run the commands above after changing native
code or `app.json`. Expo Go is not supported (custom native module).

Phone setup for development: enable *Developer options* (tap Build number 7×) and *USB debugging*.
On Xiaomi/HyperOS also enable *Install via USB*.

## Android – accessibility service (default)

Works on a normal phone with accounts, no reset needed.

1. Install the app and tap **START**. It opens the Accessibility settings.
2. Turn on the **Focus** service. If it is greyed out (sideloaded app): Settings → Apps → Focus → ⋮ → *Allow restricted settings*.
3. Go back and tap **START** again. Allowed apps open normally from the tiles; any other app is sent back to Focus Garden (home screen too).
4. **STOP** turns the guard off.

After reinstalling an APK Android sometimes turns the service off – enable it again.

## Android – full kiosk (optional, Device Owner)

Lock task with an allow-list needs a Device Owner. Once, on a fresh emulator or factory-reset phone **without any accounts**:

```bash
adb shell dpm set-device-owner cz.praut.focus/expo.modules.focusnative.FocusAdminReceiver
```

When the app is Device Owner, START uses lock task instead of the accessibility service.
(Without Device Owner, Android's screen pinning would block the allowed apps too, so it is not used.)

## iOS – Screen Time shield

iOS has no kiosk mode. START shields every app except those chosen in the system picker. It requires the
`com.apple.developer.family-controls` entitlement:

1. Change the bundle identifier in `app.json` (`ios.bundleIdentifier`) to one you own.
2. Development: enable the *Family Controls* capability for your App ID in the Apple Developer portal and select your team in Xcode (`ios/*.xcworkspace` → Signing & Capabilities).
3. Distribution: [request the Family Controls (Distribution) entitlement](https://developer.apple.com/contact/request/family-controls-distribution) – approval takes days to weeks.

Note: the iOS part compiles but has not been verified on a real device yet – help is welcome.

## Dev Log

Settings → Dev Log shows a simple timeline of what the app did (START/STOP, foreground app, ignored helper windows,
redirects). Attach it to bug reports (check it for apps you do not want to share first).

## Troubleshooting

| Problem | Fix |
| --- | --- |
| `INSTALL_FAILED_USER_RESTRICTED` (Xiaomi) | Enable *Install via USB* in Developer options. |
| `adb shell input tap` fails with `INJECT_EVENTS` | Enable *USB debugging (Security settings)* on Xiaomi. |
| A game closes right after start | Check the Dev Log for the package that triggered the redirect and add it to the ignore list in `FocusAccessibilityService.kt`. |
| Focus does nothing after reinstall | Turn the accessibility service off and on again. |
