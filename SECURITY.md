# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Report privately via GitHub: [Report a vulnerability](https://github.com/TankystaCzech123/focus-garden/security/advisories/new).

You can expect an acknowledgement within a few days. Please include the affected version, device/OS and steps to reproduce.

## Scope notes

Focus Garden uses an Android accessibility service that only reads which app is in the foreground (it does not read
screen content) and sends no data anywhere. Reports about misuse of this permission are especially welcome.
