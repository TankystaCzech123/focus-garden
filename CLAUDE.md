# Focus Garden – project guide

Gamified focus app for Android + iOS: Expo (React Native, TypeScript) + a local native module (Kotlin/Swift). No backend. KISS.

## Commands
- `npm run typecheck` · `npm test` (node:test, `tests/`) · `npm run android` · `npm run ios`

## Layout
- `src/rules.ts` – pure game rules (streak, ice cubes, rewards, garden). Keep it free of React/storage imports and tested.
- `src/` – screens/components; `modules/focus-native/` – native module; `docs/` – architecture, rules, setup, privacy.

## Rules
- Conventional Commits (`feat:`, `fix:` ...): releases and changelog are generated by release-please. Never edit `CHANGELOG.md` or version numbers by hand.
- Android focus mode uses an accessibility service; Xiaomi Game Turbo packages must stay ignored (see docs/ARCHITECTURE.md).
- Never commit secrets, keystores or personal data. Do not edit lockfiles by hand.
- Game rule changes need tests and an update of `docs/GAME_RULES.md`.
